# Ciclo 2.1 — Aplicaciones y Herramientas Computacionales

**Objetivo:** consolidar habilidades prácticas mediante el uso de herramientas
computacionales avanzadas y aplicaciones en investigación cuantitativa.

**Ponderación:** 200 puntos · 40% del entorno · ~4 semanas · modalidad de coloquios.

## Contenidos

- Software estadístico: uso de R, SPSS, SAS y Python.
- Big data y análisis de datos: técnicas para el manejo de grandes volúmenes de datos.
- Visualización de datos: herramientas y técnicas para una visualización efectiva.
- Investigación aplicada: desarrollo de un proyecto de investigación cuantitativa.
- Ética en la investigación cuantitativa: consideraciones éticas en la recolección y el
  análisis de datos.
