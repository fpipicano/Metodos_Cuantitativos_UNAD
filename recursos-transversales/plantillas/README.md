# Plantillas

Plantillas reutilizables para las entregas del entorno.

Ejemplos de archivos que pueden ir aquí:

- `plantilla-reporte-analisis.docx` — estructura de un informe de análisis cuantitativo.
- `plantilla-proyecto-investigacion.docx` — propuesta del proyecto aplicado (Ciclo 2.1).
- `plantilla-presentacion-coloquio.pptx` — presentación para el coloquio del Momento 2.
- `plantilla-script.R` / `plantilla-notebook.ipynb` — encabezado y estructura estándar de código.
