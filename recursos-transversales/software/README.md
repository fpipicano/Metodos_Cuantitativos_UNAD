# Software del entorno

Guías de instalación y configuración de las herramientas del componente práctico. Agrega
aquí un archivo por herramienta (p. ej. `instalacion-R.md`, `instalacion-python.md`).

| Herramienta | Uso principal | Notas |
|---|---|---|
| **R** + RStudio | Análisis estadístico y ciencia de datos | Software libre. Paquetes sugeridos: `tidyverse`, `car`, `psych`, `forecast`. |
| **SPSS** | Análisis estadístico | Herramienta institucional disponible en la UNAD. |
| **SAS** | Análisis estadístico avanzado | Verificar acceso institucional / SAS OnDemand. |
| **Python** | Análisis de datos y visualización | Paquetes sugeridos: `pandas`, `numpy`, `statsmodels`, `matplotlib`, `seaborn`. |

> Recuerda documentar la versión de cada herramienta usada en las prácticas para garantizar
> la reproducibilidad de los resultados.
