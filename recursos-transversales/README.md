# Recursos transversales

Material que se utiliza a lo largo de **todo** el entorno, sin pertenecer a un ciclo
específico.

| Carpeta | Contenido |
|---|---|
| [`software/`](software/) | Guías de instalación y configuración de R, SPSS, SAS y Python. |
| [`bases-datos/`](bases-datos/) | Conjuntos de datos reutilizables en varios ciclos, con su diccionario. |
| [`plantillas/`](plantillas/) | Plantillas de entrega, reportes y presentaciones. |
| [`bibliografia/`](bibliografia/) | Referencias del microcurrículo y lecturas complementarias. |

> Si un dataset se usa en un solo ciclo, guárdalo dentro de la carpeta `datasets/` de ese
> ciclo. Si se reutiliza en varios, ponlo aquí en `bases-datos/` y referéncialo desde la
> [matriz documental](../matriz-documental.md).
