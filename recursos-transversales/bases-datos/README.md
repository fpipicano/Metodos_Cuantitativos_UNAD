# Bases de datos (transversales)

Conjuntos de datos reutilizables en varios ciclos del entorno.

**Buenas prácticas:**

- Acompaña cada dataset de un diccionario de datos (`<nombre>-diccionario.md`) que describa
  cada variable, su tipo y sus unidades.
- Indica la fuente y la fecha de consulta u obtención de los datos.
- Prefiere formatos abiertos (`.csv`) para máxima compatibilidad entre R, SPSS, SAS y Python.
- Registra cada dataset en la [matriz documental](../../matriz-documental.md).

| Archivo | Descripción | Formato | Ciclos donde se usa |
|---|---|---|---|
| _(ejemplo)_ `ventas-ti.csv` | _(completar)_ | csv | 1.1, 1.2 |
