# Notebooks de ejemplo · técnicas avanzadas

Un notebook de ejemplo del tutor por cada técnica del menú de la Parte 2, sobre datos
similares (no el dataset de la cohorte). Sirven de **andamiaje**: el estudiante los estudia
para comprender el proceso analítico completo y luego adapta la estructura a su análisis
—no los copia.

_Sugerencia:_ `ejemplo-op1-sem.ipynb`, `ejemplo-op2-series.ipynb`,
`ejemplo-op3-bayes.ipynb`, `ejemplo-op4-ml.ipynb`.
