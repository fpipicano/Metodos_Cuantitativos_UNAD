# Dataset compartido de la cohorte

El tutor provee aquí un **dataset real de TI**, único para toda la cohorte del período, con:

- el archivo de datos,
- **diccionario de variables** (tipos, escalas, descripción),
- **fuente y contexto de recolección**,
- **problema analítico rector** que orienta los análisis sin prescribir los métodos,
- **guía de inicio rápido**.

Todos los estudiantes trabajan el mismo dataset: las diferencias en los resultados revelan
decisiones analíticas distintas y alimentan la revisión entre pares.
