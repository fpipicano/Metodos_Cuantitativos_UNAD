# Plantillas · Ciclo 2

- `diagnostico_regresion_plantilla.ipynb` — esqueleto de diagnóstico de regresión (Semana 7):
  VIF (`variance_inflation_factor`), Breusch-Pagan (`het_breuschpagan`), distancia de Cook,
  Q-Q de residuos y residuos vs. predichos. Cada celda de código va seguida de preguntas de
  interpretación en Markdown.
- `plantilla-reporte-cientifico` — estructura del reporte en formato paper (8–10 pág, APA/IEEE):
  Introducción, Metodología, Resultados Parte 1, Resultados Parte 2, Discusión (con
  implicaciones para la tesis) y Referencias.
