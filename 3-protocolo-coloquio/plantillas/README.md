# Plantillas · Ciclo 3

- `plantilla-protocolo` — Protocolo Metodológico Cuantitativo con las **10 secciones**
  (10–12 pág, formato publicable, APA 7): posicionamiento epistemológico, pregunta e
  hipótesis, constructos/variables/operacionalización, diseño empírico, población/muestra/
  potencia, plan de análisis estadístico, análisis de sensibilidad, ética, reproducibilidad y
  cronograma.
- `plantilla-coloquio` — presentación para la defensa oral (15 min + 10 min de preguntas).
