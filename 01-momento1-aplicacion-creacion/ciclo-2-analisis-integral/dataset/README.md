# Dataset compartido — Ciclo 2

Toda la cohorte trabaja el **mismo dataset real de TI**, provisto por el tutor al inicio del
ciclo. Coloca aquí:

| Archivo | Descripción |
|---|---|
| `dataset-cohorte.csv` | Dataset real de TI (fuente y contexto de recolección documentados). |
| `diccionario-variables.md` | Nombre, tipo, escala de medición, descripción y valores posibles de cada variable. Indispensable para la reproducibilidad. |
| `problema-analitico-rector.md` | Descripción del problema que orienta los análisis sin prescribir los métodos. |
| `guia-inicio-rapido.md` | Instrucciones de carga y exploración inicial (orienta la Semana 5). |
