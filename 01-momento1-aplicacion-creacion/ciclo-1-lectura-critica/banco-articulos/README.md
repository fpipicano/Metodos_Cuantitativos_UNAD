del DTI** (CRIC, IASC, IoTCI, ADVTD), cada uno con un método distinto, para garantizar
cobertura metodológica completa. Cada estudiante analiza **un** artículo (sin duplicados en
el grupo), preferiblemente de una línea distinta a su interés doctoral.

Coloca aquí el PDF de cada artículo (o un archivo de acceso con su enlace). Todos son de
