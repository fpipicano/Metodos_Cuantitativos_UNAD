# Artículo modelo — Webconferencia Semana 2

Artículo que el tutor analiza **en vivo** durante la webconferencia de la Semana 2, aplicando
las 8 operaciones doctorales paso a paso. Es **distinto** de los artículos del banco (los
estudiantes no lo analizan; les sirve como demostración del proceso).

## Artículo seleccionado

Chen, S., & Ye, J. (2023). *Understanding consumers' intentions to purchase smart clothing
using PLS-SEM and fsQCA*. **PLOS ONE, 18**(9), e0291870.
DOI: 10.1371/journal.pone.0291870 · Acceso abierto CC BY 4.0 · Q1.

Elegido por: paradigma declarado explícitamente (Complexity Theory + post-positivismo), IRB
explícito, hipótesis rechazadas para el debate (H2c, H6a, H8a), método dual PLS-SEM + fsQCA
y datos CSV disponibles para ejecutar la verificación de potencia en Python en vivo.

## Qué va en esta carpeta

- PDF del artículo modelo (o archivo con el enlace al PDF de PLOS ONE).
- `plan-webconferencia-s2.md` — guion de la sesión (90 min) mapeado a las 8 operaciones, con
  las conexiones a artículos del banco. El guion detallado está en la carpeta interna
  `gestion-docente/` (`Candidatos_Webconferencia_Semana2_DTI.xlsx`).
