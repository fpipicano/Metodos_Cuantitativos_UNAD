# 01 · Momento 1 — Aplicación y Creación

Primer momento del entorno. Permite la interacción inicial y continua entre estudiantes y
docentes, con acompañamiento permanente y realimentación continua para **aplicar** los
conocimientos y **crear** nuevos escenarios de investigación e innovación.

- **Ponderación:** 60% del entorno (300 puntos)
- **Duración:** ~12 semanas
- **Ciclos:**
  - [`1.1-fundamentos`](1.1-fundamentos/) — Fundamentos de Métodos Cuantitativos (100 pts · 20%)
  - [`1.2-analisis-avanzado`](1.2-analisis-avanzado/) — Análisis Estadístico Avanzado (200 pts · 40%)

Cada ciclo contiene sus propias carpetas `lecturas/`, `datasets/` y `recursos/`.
