# Ciclo 1.2 — Análisis Estadístico Avanzado

**Objetivo:** profundizar en técnicas estadísticas avanzadas para el análisis de datos y la
interpretación de resultados complejos.

**Ponderación:** 200 puntos · 40% del entorno · ~8 semanas.

## Contenidos

- Regresión y correlación: análisis de regresión simple y múltiple.
- Pruebas de hipótesis: formulación y contraste.
- ANOVA y MANOVA: análisis de varianza y modelos multivariantes.
- Métodos multivariantes: análisis de componentes principales y análisis discriminante.
- Series temporales y análisis predictivo: modelos ARIMA y técnicas de predicción.
